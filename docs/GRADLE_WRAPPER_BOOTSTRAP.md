# Gradle Wrapper Bootstrap

V5.16 deliberately does **not** ship a hand-written or fabricated `gradle-wrapper.jar`. The official Gradle Wrapper must be generated by a real Gradle installation.

## Required host

- JDK 17+
- Gradle **8.11.1**
- Android SDK/Build Tools/NDK required by the Android build contract

## Generate

From the repository root:

```bash
bash tools/bootstrap_gradle_wrapper.sh
```

The script requires `gradle --version` to report exactly `8.11.1`, then runs the official `wrapper` task and verifies:

- `gradlew`
- `gradlew.bat`
- `gradle/wrapper/gradle-wrapper.jar`
- `gradle/wrapper/gradle-wrapper.properties`

The generated Wrapper files should be committed to the public repository. Do not replace the JAR with a downloaded, truncated, placeholder, or hand-written file.

## Why this remains a host step

The current packaging environment has no Gradle installation and no existing Wrapper JAR. Creating a fake JAR would make the repository appear reproducible without actually being so. V5.16 therefore fails closed until a real Gradle 8.11.1 host generates the Wrapper.
