# Competitive Positioning (Factual)

This project should be presented as an **offline research system**, not merely an offline chat UI.

The differentiating technical claims to demonstrate are:

- local GGUF inference rather than cloud inference;
- a local, versioned evidence corpus;
- deterministic retrieval before generation;
- stable evidence/source IDs;
- research-mode planning for synthesis, comparison, multi-hop and timeline tasks;
- explicit insufficient-evidence behavior;
- contradiction surfacing rather than silent source selection;
- citation validation against retrieved evidence;
- offline-policy auditing;
- device-level latency, memory and storage measurements;
- reproducible model/corpus/native-source checksums.

Do not claim superiority over another project unless the same task, device, model, corpus and measurement procedure are documented and reproduced.
