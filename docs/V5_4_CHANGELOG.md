# V5.4 Change Log

## Research engine
- Explicit Auto/Synthesis/Compare/Multi-hop/Timeline mode selection.
- Better multilingual tokenization and entity extraction.
- Retrieval query expansion across the question and extracted entities.
- Minimum evidence score threshold to reduce weak retrieval matches.
- Explicit insufficient-local-evidence path.
- Unsupported model-generated citation IDs are removed rather than displayed as valid evidence.
- Native model is released after a completed generation to reduce retained native memory.

## UI
- Research mode chips.
- Local GGUF state.
- Model SHA-256 preview.
- Managed storage indicator.
- Native inference state remains visible and truthful.

## Integrity
V5.4 does not claim physical-device validation, network-capture proof, or bounty readiness. Those remain finalization gates.
