# Baseline model pin

## Development baseline

Repository: `Qwen/Qwen3-1.7B-GGUF`
Quantization: `Q4_K_M`
License: Apache-2.0

The official Qwen repository currently publishes Qwen3-1.7B GGUF variants. The Q4_K_M file is the intended resource-constrained baseline; its exact file SHA-256 must be recorded after download and before device testing.

Do not claim the model checksum is verified until the actual GGUF file has been downloaded and hashed.

The model is a **baseline**, not a permanent final-model decision. Final selection must be based on device memory, speed and research benchmark results.
